Mida is a lightweight AI‑powered A/B testing platform for websites. It enables running experiments, personalizing pages, and measuring conversions without developers. The free plan includes 100K monthly tracked users, and the service focuses on simplicity and speed for marketers and product teams.

**Areas:** A/B Testing · AI · Marketing · Analytics · SaaS · Platform

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Mida: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
